**Empowering** is a [[Limited Action]] consisting in rendering one or more [[Game Object|Game Objects]] **Empowered**. Players may only **Empower** Game Objects when directed to by [[Game Effect|Game Effects]].

**Empowered** is a binary state. A [[Game Object]] is Empowered or it isn’t. An **Empowered** Game Object **can not be Empowered**. If a Game Object is instructed to be Empowered when it is already Empowered, **nothing additional happens**.

Some effects may grant a Game Object permission to be Empowered multiple times. Such an effect ignores the above mentioned restriction.

“Empowered” is a state for Game Objects on [[The Board]] that other game effects and abilities can reference. When a Game Object becomes Empowered as a result of the Empower game action, that is an event that can similarly be referenced by game effects and [[Ability|abilities]].
