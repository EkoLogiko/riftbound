**Linked Abilities** are a set of [[Ability|Abilities]] with one or more of the *Component Abilities* referencing the other [[Ability|Abilities]] in the set.

*Component Abilities* can reference other [[Ability|Abilities]] in the set by means of referencing those [[Ability|Abilities]] directly or by referencing [[Game Object|Game Objects]] affected by or mentioned in another [[Ability]] in the set.

In order for a set of [[Ability|Abilities]] to be **Linked**, they must be present in the printed Effect or [[Rules Text]] of the same [[Game Object]], or be granted by the same source to another [[Game Object]].

>*Example*: The Zero Drive’s effect text reads **“[[Deathknell]] [>] Banish me.”** The granted deathknell ability is linked with the Zero Drive’s activated ability.

Linked Abilities can contain component [[Ability|Abilities]] of **any type**. A component Linked Ability that references a [[Game Object]] affected by another [[Ability]] in the set may only interact with [[Game Object|Game Objects]] affected by the [[Ability|Abilities]] it is Linked with.

> *Example*: The Zero Drive is an Equipment gear whose rules text reads in part **“[3][B], Banish this: Play all units banished with this, ignoring their costs.”** Any units banished by effects other than component Linked Abilities in the same set as the activated ability cannot be played when resolving the activated ability.
