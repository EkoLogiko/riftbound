A **Game Object** is any game piece that can produce one or more [[Game Effect|Game Effects]] or grant prerequisites for players to take [[Game Action|Game Actions]].
A Game Object does not include nor preclude any inherent properties beyond the ability to produce, or act as the prerequisite for, [[Game Effect|Game Effects]] and [[Game Action|Game Actions]].

It can be a literal object or a logical object.

Game Objects include, but are not limited to, the following: 
- [[Main Deck]] cards in any zone 
- [[Rune|Runes]] in any zone 
- [[Champion Legend]]s 
- [[Battlefield]] 
- [[Token|Tokens]] in any zone 
- [[Ability]] of any type on the chain 
- [[Counters]] and other status markers

A Game Object that *changes zones* to or from a [[Non-Board Zone]] becomes a new object for the purposes of tracking that object. Also, all temporary modifications of all kinds cease to be tracked on it in all capacities.

A Game Object can have any of the following statuses (non-exhaustive): 
- [[Attached]]
- [[Attacker|Attacking]]
- [[Buff|Buffed]]
- [[Banish|Banished]]
- [[Control|Controlled]]
- [[Defender|Defending]]
- [[Empowered]]
- [[Equipped]]
- [[Exhaust|Exhausted]]
- [[Facedown]]
- [[Ready|Readied]]
- [[Replace|Replaced]]
- [[Reveal|Revealed]]
- [[Stun|Stunned]]
- any applied [[Layer]] alternations.

Two Game Objects are **friendly** if they share a [[Control|controller]], or if one’s controller is teammates with the other’s.
Two Game Objects are **enemies** if one’s [[Control|controller]] is an opponent of the other’s.
